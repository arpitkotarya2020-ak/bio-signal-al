# 🧠 EEG & EMG Mudra Analysis

This repository contains data and code for analyzing the neurological and muscular activity (EEG & EMG) associated with performing **10 different mudras**, collected using the **EXG Bio Amp (Pill form)** by [Upside Down Labs](https://upsidedownlabs.tech/). The goal is to understand and classify mental and physical states while performing specific hand gestures (mudras).
